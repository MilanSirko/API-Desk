COLLECTIONS AND FOLDERS

Collections vs folders

Both help organize requests, but they work differently.

📁

Folders

A folder groups saved requests in your workspace. Requests inside a folder remain the same saved requests you can open and edit.

  • Use folders to organize your original requests.
  • Moving a request into a folder removes it from All requests.
  • Deleting a folder moves its requests back to All requests.
▤

Collections

A collection stores request copies and can apply shared settings to those copies.

  • Use collection headers, variables, authentication and settings across its requests.
  • Requests in a collection are copies, separate from their originals.
  • Deleting a collection removes the collection and its copies.
i

Choose a folder to group your saved work. Choose a collection when you want request copies that use common configuration.
