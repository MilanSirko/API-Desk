MAKING A REQUEST

Query params

Use query parameters to pass filters, search terms, sorting options or paging information in a URL.

Add each parameter as a key and value in the Params tab. APIDesk appends enabled rows to the URL after a question mark.

PARAMETER ROWS
search    books
page      2
sort      title

Those rows produce this URL:

https://api.example.com/books?search=books&page=2&sort=title

Parameter names and values are URL encoded before sending. For example, a space is encoded as %20. Use the Params table when you want to switch individual parameters on or off.

i

Avoid putting passwords or private tokens in a URL. URLs can appear in browser history and server logs. Use the Auth tab or a request header for credentials.
